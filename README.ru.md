# Драйвер NPU для SM8250

[English version](README.md)

Проект драйвера Linux для нейронного ускорителя Qualcomm SM8250. Проект
использует Rust workspace. Настройки конкретной платы хранятся в проекте,
который подключает драйвер. Прошивка и файлы моделей поставляются отдельно.

## Структура проекта

| Путь | Ответственность |
| --- | --- |
| `crates/npu-domain` | Общая логика жизненного цикла ускорителя, прошивки и графов. |
| `crates/npu-sm8250` | Протокол прошивки SM8250, очереди IPC, последовательности запуска и остановки. |
| `crates/npucc-sm8250` | Описания тактов, сбросов и доменов питания SM8250. |
| `kernel/` | Точки входа модулей Linux, адаптеры ядра и Kbuild. |

## Модуль Linux

Для сборки модуля ускорителя нужны подготовленное ядро с поддержкой Rust и
соответствующий `Module.symvers`.

```sh
make -C "$KERNEL_BUILD" ARCH=arm64 CROSS_COMPILE=aarch64-linux-gnu- M="$PWD/kernel" modules
```

`sm8250_npu.ko` привязывается по `qcom,sm8250-npu`. При привязке драйвер
проверяет запуск и остановку прошивки через Qualcomm PAS. В Device Tree
нужно указать путь к подписанному образу MDT в свойстве `firmware-name` и
область памяти для образа в `memory-region`. Подписанный образ и его сегменты
следует установить в обычный каталог прошивок Linux.

### Конфигурация платы

Контроллер тактов принимает необязательное свойство
`qcom,cx-performance-state`, которое задаёт уровень производительности CX
в Device Tree платы.

### Пробный прогон графа

Для проверки в узле ускорителя указываются пути `qcom,validation-aco`,
`qcom,validation-weights`, `qcom,validation-relocations` и
`qcom,validation-input`. Необязательный `qcom,validation-output` задаёт
эталонный тензор для побайтного сравнения.

У всех перечисленных ниже свойств префикс `qcom,validation-`.

| Окончание имени | Значение |
| --- | --- |
| `aco-size`, `weights-size`, `workspace-size`, `input-size`, `output-size` | Размеры в байтах. |
| `relocation-count` | Число восьмибайтовых записей релокации. |
| `network-id`, `first-block-size`, `layer-count` | Параметры загрузки графа. Размер первого блока указывается в байтах. |
| `input-patch-id`, `output-patch-id` | Идентификаторы патчей тензоров. |
| `load-patches` | Необязательные записи патчей прошивки по шесть ячеек. |

Драйвер выполняет граф дважды и сравнивает результаты. Раскладку, модель и
тензоры предоставляет проект, который подключает драйвер.
